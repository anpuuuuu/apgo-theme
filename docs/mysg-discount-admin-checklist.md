# MY/SG 满100减10 后台配置清单

本文件用于在 Shopify Admin 完成真实结账规则，使主题前端展示与结账价格一致。

## 1) 折扣规则（必须）

- 目标：马来西亚与新加坡市场，订单满 100 后减 10（本地币）。
- 推荐优先方案：在 Admin 建立自动折扣（Automatic discount）。
- 若单个自动折扣无法同时覆盖 MYR/SGD 的“同数值本币”逻辑，使用 Shopify Function 实现 market-aware 规则。

### 验证点

- MY 市场：购物车金额 `<100` 不折扣，`>=100` 折扣 10 MYR。
- SG 市场：购物车金额 `<100` 不折扣，`>=100` 折扣 10 SGD。
- 折扣在 cart 与 checkout 最终一致。

## 2) 运费规则（固定 10）

- 目标：MY/SG 购物车显示固定运费 10（预结账展示）。
- 在 Shipping profiles 中确认 MY 与 SG 对应标准运费是否为 10。

### 验证点

- MY 市场结账运费为 10（无其他条件时）。
- SG 市场结账运费为 10（无其他条件时）。

## 3) 上线前回归

- 切换 MY 与 SG 两市场分别测试：
  - 购物车 99：不触发满额折扣。
  - 购物车 100：触发减 10。
  - 购物车显示四行：Subtotal / Shipping fee / Discount / Total。
  - 结账页金额与购物车 Total 一致。
